O **Hemora** é uma plataforma web desenvolvida para uma ONG fictícia com o objetivo de mobilizar, conscientizar e engajar a população sobre a importância vital da doação de sangue no Brasil. O sistema conecta a necessidade urgente dos hemocentros à iniciativa solidária de doadores e voluntários através de uma interface clara e direta.

## 🎯 A Importância da Causa

A doação de sangue é um ato de solidariedade e cidadania que sustenta a saúde pública. O projeto foi estruturado com base em três pilares fundamentais:

* **Salva Vidas:** Uma única doação coletada é capaz de salvar a vida de até quatro pessoas.
* **Abastecimento Contínuo:** O sangue é o insumo essencial para atendimentos de urgência, emergência, cirurgias de grande porte e tratamentos complexos de doenças crônicas.
* **Insubstituível:** Não existe tecnologia no mundo capaz de produzir sangue artificialmente, tornando o doador humano 100% insubstituível.

## ⚡ Pilares Técnicos da Plataforma

Embora seja uma plataforma conceitual, o projeto foi construído seguindo rigorosos padrões profissionais de desenvolvimento de software para simular um ambiente real de produção:

### ♿ Acessibilidade (a11y)
Desenvolvido com foco em inclusão digital. A estrutura lógica e o uso de tags semânticas garantem que o site seja fácil de navegar por qualquer pessoa, mantendo total compatibilidade com tecnologias assistivas e leitores de tela.

### 🚀 Alta Performance
O código foi otimizado para garantir carregamento rápido e consumo mínimo de dados, assegurando que o tempo de resposta da interface não seja uma barreira em momentos de urgência para a causa.

### 📐 Organização e Arquitetura Clean
A separação de responsabilidades e a hierarquia visual clara guiam a experiência do usuário de forma intuitiva, otimizando o fluxo de conversão para novos doadores e voluntários.
